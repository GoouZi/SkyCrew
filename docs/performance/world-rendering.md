# 程序化云的性能边界

默认世界包含 37 个共享原网格和材质的云实例，最多生成 48 个。每个网格含 40,688 个三角形，当前使用原版网格。每个 MeshInstance3D 由引擎进行独立视锥裁剪，并设置 4,800 米可见距离。

生成只发生在进入场景、主动重建或编辑器参数变化时。运行时按风速移动既有节点并回绕位置，保持数量稳定。生成器不创建云的碰撞体。边界包围盒为原网格向外扩大 0.0004 个局部单位，覆盖原版世界空间顶点位移。

程序化预览生成的实例不写入场景文件。原版材质参数直接沿用，当前基线尚无自动网格 LOD。地图继续扩展时需基于当前原版效果验证 LOD、分区加载及远景过渡，并记录 GPU 帧时间与可见几何量。视口和默认独立窗口均为 1920 × 1080。
